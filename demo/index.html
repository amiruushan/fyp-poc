SCOPE / 04
01

Feature vectors

These changes were made to model inputs. The experiment did not show that a valid, visible or working phishing webpage can be edited this way.

02

Eligible subset

The primary comparison includes starts with a factual S cue and a distinct same-family M cue: 344 logistic and 299 boosted-tree starts.

03

Dataset and protocol

Collection source is tied to class, the 2% detector target was chosen using development results, and normalized perturbation magnitude was not logged.

For exact methods and caveats, see docs/step-11-frozen-final-results.md in the repository.
